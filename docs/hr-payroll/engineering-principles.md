# HR / Payroll engineering principles (public)

## Privacy first

HR and payroll data are high-sensitivity. Public materials discuss controls, not people.

## Principles

- Minimize personal data in logs and diagnostics.
- Record rules and groups enforce need-to-know.
- Statutory outputs (e.g., social insurance / wage file concepts) are gated and reviewed.
- Attendance and correction flows need explicit authorization models.
- Never publish employee identifiers, national ID numbers, or payroll amounts in examples.
