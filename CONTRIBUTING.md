# Contributing

Thank you for helping improve this engineering showcase.

## Accepted contributions

- Clarifications to architecture and governance documentation
- Additional synthetic examples (obviously fictional values only)
- Diagrams that do not embed real infrastructure identity
- Case-study wording improvements that preserve privacy boundaries

## Not accepted

- Private application source
- Vendor/upstream trees copied from internal mirrors
- Real hostnames, IP addresses, database names, or credentials
- Customer or employee personal data
- Screenshots with identifiable business documents
- “Fixes” that require publishing proprietary compliance algorithms

## Process

1. Open an issue describing the documentation gap.
2. Keep PRs small and reviewable.
3. Run a personal scan for secrets and real infrastructure identifiers before submitting.
4. Do not reference private repository paths or live operational identifiers.

## Code of conduct (short)

Be precise, respectful, and security-conscious. Speculative claims without evidence do not belong in this repository.
