# Security Policy

## Supported material

This repository publishes documentation and synthetic examples only. It does not operate production systems.

## Reporting a vulnerability

If you believe this public repository accidentally contains:

- credentials or private keys
- personal data
- operable infrastructure identity that should not be public
- other sensitive material

please open a **private** security advisory on GitHub (preferred) or file an issue **without pasting secret values**.

Do **not** attach dumps, key files, or customer data to public issues.

## Scope exclusions

Issues that only affect a private deployment of Community ERP Platform (non-public source) should be reported through the private project’s security channel—not by uploading private source here.

## Safe disclosure expectations

- Do not exploit production systems.
- Do not request or publish live credentials.
- Provide file paths and finding type; omit secret values.
